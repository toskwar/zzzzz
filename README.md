# End Stone Creeper Spawner

Клиентский мод для Fabric, Minecraft **1.21.4**. Камень Края (эндерняк) выглядит как клетка спавнера с крипером внутри. Это касается и блока в мире, и предмета в инвентаре и в руке.

## Сборка
;;;;
Нужны JDK 21 и интернет (Gradle скачает Minecraft и Fabric API).

```
./gradlew build
```

Готовый мод: `build/libs/endstone_spawner-1.0.0.jar`. Положите его в папку `mods` рядом с Fabric API (0.119.4+1.21.4 или новее для 1.21.4).

Для запуска из папки проекта: `./gradlew runClient`.

## Сборка через GitHub

Если JDK ставить не хочется:

1. Создайте на GitHub пустой репозиторий и загрузите в него содержимое проекта (вместе с папкой `.github`).
2. Откройте вкладку Actions, дождитесь зелёной галочки у запуска `build` (или нажмите Run workflow).
3. Внутри запуска скачайте артефакт `Artifacts` и достаньте из него `endstone_spawner-1.0.0.jar`. Файл с `-sources` в имени не нужен.

## Как это работает

- `assets/minecraft/models/block/end_stone.json` заменяет ванильную модель. Состоит из клетки (`block/spawner`), внутренних стенок и крипера, собранного из шести параллелепипедов с UV от `entity/creeper/creeper`.
- `assets/minecraft/blockstates/end_stone.json` поворачивает блок случайно на 0/90/180/270°, чтобы криперы смотрели в разные стороны.
- `assets/minecraft/atlases/blocks.json` добавляет текстуру крипера в атлас блоков.
- `EndStoneSpawnerClient` переводит камень Края на слой `cutout`: у клетки прозрачные дырки.

## Что можно поправить в `end_stone.json`

- `light_emission` у крипера (15) и у стенок (6) задаёт свечение. Крипер внутри непрозрачного блока без него был бы чёрным.
- Крипер уменьшен до 0.4 от ванильного размера и стоит по центру клетки. Элементы по порядку: 0 клетка, 1–6 стенки, 7 голова, 8 туловище, 9–12 ноги.

## Производительность

Крипер входит в модель каждого блока камня Края, в том числе скрытых внутри острова. Граней в чанках Края становится заметно больше, чем в ваниле. На слабых ПК могут просесть FPS и скорость подгрузки чанков. Если так, удалите из `end_stone.json` элементы 9–12 (ноги) или оставьте одну голову.
